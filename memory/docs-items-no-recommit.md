Папки `docs/items/` (~3000 PNG+JSON предметов) и `docs/walls/` добавлены в репозиторий вручную через коммит `0b3ea5f` → `d66623f`. Из-за лимита GitHub (100 файлов / операция) пуш иногда тайм-аутится. **Не добавлять эти папки в новые коммиты повторно.** Они уже в `HEAD`. Если нужно обновить — заменяй конкретные файлы, не всю папку.

**Why:** GitHub Actions / git push ломается на больших батчах (>3000 файлов).
**How to apply:** При новых изменениях в `docs/items/` делай `git add docs/items/<конкретный>.png` и коммить точечно; не используй `git add docs/` целиком.
