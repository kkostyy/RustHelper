# S-eye viewer — Mobile App

Android-клиент компаньона (внутреннее имя проекта — RustHelper): те же
6 вкладок, что и в веб-версии (Мейн / Карта / Устройства / Пробив /
Другое / Настройки), живые данные, чат команды и центр уведомлений
(колокольчик в шапке). Нативного модуля Firebase больше нет —
приложение общается двумя способами на выбор (переключается
в «Настройках»):

1. **Firebase REST** — опрос тех же узлов Realtime Database, куда пишет
   pc-client (`/team`, `/devices`, `/events`, `/client_status`,
   `/server_info`, `/chat`), раз в ~4 секунды; команды (свитчи, чат)
   отправляются POST-ом в `/commands`. Никакого `google-services.json`
   и регистрации приложения в консоли Firebase не нужно.
2. **Прямой Rust+** — телефон сам подключается к серверу игры по
   WebSocket (`ws://ip:28082`) и говорит с ним protobuf'ом (свой
   мини-кодек в `live.js`, без зависимостей). pc-client и Firebase
   вообще не нужны, но сервер должен быть доступен с телефона по сети.

Плюс режим **Демо** со статичными данными для показа без сети.
Выбор источника хранится на устройстве (AsyncStorage).

## Сборка APK через GitHub Actions (проще всего)

Локальный тулчейн не нужен:

1. Запуши этот репозиторий на GitHub (ветка `main`).
2. Вкладка **Actions** → workflow **Android APK** → запустится сам при
   пуше (или кнопкой **Run workflow**).
3. Когда сборка позеленеет — открой её, внизу в **Artifacts** скачай
   `RustCompanion-apk` (внутри — `app-release.apk`) и установи
   на телефон, разрешив установку из неизвестных источников.

CI собирает release-вариант с зашитым JS-бандлом (работает без
Metro-сервера), подписанный debug-ключом шаблона — этого достаточно для
личного использования. Для Google Play позже понадобится своя release-
подпись (отдельная настройка).

## Локальная сборка (альтернатива)

Понадобятся Node 18+, JDK 17 и Android SDK (удобнее всего через
Android Studio):

```bash
npx react-native@0.74 init RustCompanionMobile
# скопируйте ВСЕ файлы из этой папки поверх созданного проекта
# (App.js, live.js, экраны, data/, theme.js, package.json)
cd RustCompanionMobile
npm install
npm run android          # сборка+запуск на подключённом телефоне/эмуляторе
```

Готовый APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`.

Для прямого режима Rust+ манифест приложения должен разрешать
незашифрованный трафик (`android:usesCleartextTraffic="true"`) —
GitHub Actions workflow добавляет это автоматически; при локальной
сборке впиши то же самое в `<application>` в
`android/app/src/main/AndroidManifest.xml`.

## Структура

- `App.js` — оболочка: 6 табов, шапка «S-eye viewer» с колокольчиком
  уведомлений, язык RU/EN, выбор источника данных.
- `live.js` — слой данных: Firebase REST + прямой Rust+ (protobuf),
  общий live-объект для всех экранов; там же формат времени (24ч/12ч/авто).
- `notifStore.js` — центр уведомлений вне React: алармы, события,
  состав команды, трекинг, торговля; «не беспокоить», отключение
  категорий по одной (⚙ на экране уведомлений), антиспам
  (тот же заголовок не чаще раза в минуту); бейдж непрочитанных.
- `vendStore.js` — vending-избранное: звёзды в каталоге автоматов,
  сводка «Избранные товары» на Карте и вотчер (в App.js), который
  присылает kind:'shop', когда избранный предмет появился в любом
  автомате.
- `cctvStore.js` — избранные камеры CCTV (звёзды в справочнике
  «Другое → Камеры CCTV», блок избранного сверху, поиск по кодам).
- `data/lootCats.js` — словарь itemId → название + категория для
  лут-радара и сводок лута; ID сверены по дампу игровых данных
  Rust v2252 — старые гайды часто дают другие (неверные) числа.
- `srvHist.js` — история сервера за 24 ч: срезы онлайн/очереди раз
  в 5 минут, спарклайн на Пробиве («Сервер»), алерты рестарта
  (смена wipeTime) и потери/восстановления связи.
- `smeltCalc.js` + `smeltWatch.js` — переплавка: общий расчёт для
  карточки «Хранилище» и вотчер «печь доплавилась» (уведомление,
  когда руда в мониторе лежит дольше своего времени плавки).
- `deathStats.js` — аналитика смертей из лога: часы суток,
  опасные квадраты сетки A1–J10, разбивка по игрокам;
  кнопка 📋 копирует текстовую сводку (в Discord клана).
- `lookup.js` — Пробив: Steam Community XML (профиль/VAC/онлайн),
  HTML профиля (уровень Steam, баны с давностью, счётчики — без
  ключей), RustLookup — боевая статистика (K/D, точность, хедшоты,
  ресурсы, топ-серверы; первоисточник BattleMetrics; на 25.08.2026
  их бэкенд приостановлен — код ждёт его возвращения и честно
  пишет об ошибке), опциональный BattleMetrics (платный ключ),
  поиск сервера по IP, трекинг игроков (поллинг 2 мин).
- `HomeScreen.js` — Мейн: сервер-карточка, мини-карта, команда, лента.
- `MapScreen.js` — Карта: картинка сервера, тиммейты, события,
  торговые автоматы (каталог с избранным + маршрут по магазинам),
  лог смертей и аналитика по ним. Координаты: X напрямую,
  Y инвертирован (`top = SIZE - y/worldSize*SIZE`).
- `DevicesScreen.js` — Устройства: выключатели / сигнализация /
  хранилище (+ эвристика переплавки и лут-радар — сводка «что лежит
  на базе» по всем Storage Monitor'ам с категориями, поиском и
  тумблером).
- `IntelScreen.js` — Пробив: режим «Игрок» (Steam + RustLookup:
  общая/боевая статистика, ресурсы, топ серверов, риск-скор,
  отслеживание) и «Сервер» (живые плитки, алерт очереди, поиск по IP).
- `OtherScreen.js` — Другое: Бинды / Про-конфиги / Полезная информация
  (9 тем, каждая — отдельный экран) / Инструменты (5 инструментов).
- `ToolsScreen.js` — рейд-калькулятор, конвертер серы, Code Breaker,
  гены, экстракторы.
- `NotificationsScreen.js` — центр уведомлений: фильтры, поиск, время.
- `SettingsScreen.js`, `SourceModal.js` — Настройки (профиль, время,
  DND, ключ BattleMetrics, фон, виджеты, облачная копия настроек
  в Firebase-режиме) и источник + визард «Как добавить сервер?».
- `android-res/` — иконки лаунчера (S-eye viewer): mipmap PNG +
  adaptive (ic_bg/ic_fg); CI копирует их в шаблон и правит app_name.
- `data/*.js` — офлайн-справочники (рейд, бинды, CCTV, монументы).
