=== РАЗДЕЛ 2: ТЗ / ПРАВКИ ===
2.1 ИНТЕРФЕЙС И КАРТЫ
- Миникарта: убрать квадрат, растянуть на почти всю ширину экрана
- Основная карта: открытие во весь экран по тапу; зум двумя пальцами; перетаскивание
- Категория «Магазины»: папка «Магазины» + перенос автоматики/маршруты
- Раздел смертей: полностью убрать из виджета

2.2 УСТРОЙСТВА И УМНЫЙ ДОМ
- Фильтрация: убрать вывод всех устройств подряд
- Групповое управление: мультивыбор + одновременное вкл/выкл

2.3 ПРОБИВ / ВНЕШНИЕ СЕРВИСЫ
- Заглушка API: при отсутствующем API карточка на весь экран, числовые поля = 0
- RustWho: парсинг https://www.rustwho.com
- Chrome Extension: забор токена/данных при регистрации; отправка: Расширение → ПК-сервер → Телефон

2.4 НАСТРОЙКИ / АККАУНТЫ / АДМИН
- Бинды: новые горячие клавиши в «Другое»
- Система аккаунтов: внутренняя авторизация
- Админ-панель: выдача прав администратора; управление настройками ютуберов

2.5 БАЗА ЗНАНИЙ / ИНСТРУМЕНТЫ
- Актуализация: Kevlar + MK-A
- Чаи: рецепты и эффекты в 3 стадиях (Basic/Advanced/Pure)
- Инструменты: привести в соответствие с макетами из папки reference/

2.6 ДИЗАЙН / СТИЛИСТИКА
- Уйти от «ИИ-стиля»; уникальный UI
- Сохранить Liquid Glass + доработать
- Кастомная отрисовка эмоций/эмодзи в единой палитре
